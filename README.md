# 自在動一點

一個手機優先的家庭運動 Tracker，協助父母從四個簡單居家動作開始，累積規律、安全與做得到的身體經驗。

## 第一階段

- 爸爸、媽媽各自查看紀錄，不互相比較。
- 每週目標 2–3 次、每次約 5–8 分鐘。
- 共同動作：椅子坐站、扶牆踮腳、空手划船、扶桌髖鉸鏈。
- 追蹤完成狀態、身體感受與是否願意再次參與。
- 每日觀念卡優先引用台灣政府及醫療機構的正式衛教來源。

## 隱私

公開網站只包含去識別化的運動摘要。疾病、用藥、跌倒細節及家庭 Profile 應存放於本機 `private/`，該目錄不會加入版本控制。

## 本機開發

```bash
npm install
npm run dev
```

## GitHub Pages

推送到 `main` 後，GitHub Actions 會建立靜態網站並發布到 GitHub Pages。
